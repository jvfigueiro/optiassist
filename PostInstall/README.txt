========================================================================
OptiAssist - Offline Installers Folder (PostInstall)
========================================================================

Place offline application installers (.exe / .msi / .msixbundle) here
that you want to install automatically and offline on computers.

Standard recognized installer names:
- ChromeSetup.exe
- 7ZipSetup.exe
- OfficeSetup.exe
- WinRAR-x64.exe
- vlc-setup.exe
- AcrobatReader.exe
- AnyDesk.exe
- FirefoxSetup.exe
- npp.Installer.x64.exe

Note:
If the corresponding offline installer is not present in this folder,
OptiAssist will use the official Windows fallback (Winget) to download
and install silently when an internet connection is available!

# System Cleaner & Optimizer Add-on

The **System Cleaner & Optimizer** module provides deep Windows maintenance, junk removal, and privacy trace cleaning.

## Features
- **User Temporary Files**: Cleans user `%TEMP%` and application cache stores.
- **Windows System Temp**: Cleans system-level files in `C:\Windows\Temp`.
- **Windows Update Cache**: Purges downloaded update installers in `SoftwareDistribution\Download`.
- **Thumbnail Cache**: Deletes Windows Explorer database files (`thumbcache_*.db`).
- **Explorer Shellbags**: Cleans folder view settings, layout positions, and browsing history from the registry.
- **Windows Clipboard**: Flushes text, images, and data from active memory buffers.
- **DNS Resolver Cache**: Flushes the local DNS client cache to repair network address resolution.
- **System Event Logs**: Clears Windows Event Logs (`Application`, `System`, `Security`, `Setup`).
- **Memory Dumps & BSOD Reports**: Cleans crash memory dumps (`MEMORY.DMP`, minidumps, live kernel reports).
- **MUICache**: Clears application execution strings from the Windows Registry.
- **Windows Prefetch**: Purges execution prefetch traces from `C:\Windows\Prefetch`.
- **Empty Recycle Bin**: Permanently deletes files from all recycle bins on all attached volumes.
- **Windows Defender Temp & Scans**: Clears detection history caches, operational support logs, and engine cache.
- **Windows Error Reporting (WER)**: Cleans crash queues and error reports from `ProgramData` and `LocalAppData`.
- **Delivery Optimization Cache**: Purges peer-to-peer Windows update cache packages.
